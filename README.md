# Квиз «Сможете провести урок йоги?»

Интерактивная профпроба Академии Йоги из шести вопросов. Ответы влияют на сценарий урока, разбор и рекомендуемый курс в подарок.

## Запуск

Откройте [index.html](index.html) в браузере. Сборка и установка зависимостей не нужны.

## Заявки

Поля имени и телефона работают в режиме предпросмотра. Для отправки из квиза укажите в `LEAD_ENDPOINT` адрес обработчика на том же домене. Обработчик получает JSON с полями `name`, `phone`, `gift`, `goal` и `tracking` и после сохранения должен вернуть `{"ok":true}`. В предпросмотре доступна ссылка на форму Академии.

## Маркетинговые варианты

- [Билет на старт](https://vasyok111-arch.github.io/yoga-teacher-quiz/designs/ticket/) — вишнёвый фон, розовые акценты, перфорированный купон.
- [Прямой эфир](https://vasyok111-arch.github.io/yoga-teacher-quiz/designs/live/) — красные сигналы, спортивное табло и графитовые рамки.
- [Дроп](https://vasyok111-arch.github.io/yoga-teacher-quiz/designs/drop/) — ультрафиолетовый постер и оранжевые блоки оффера.
- [Премьера](https://vasyok111-arch.github.io/yoga-teacher-quiz/designs/premiere/) — кинопостер с анимационными персонажами и золотым светом.

Во всех четырёх: шесть вопросов с прежними ветвлениями, подсказки следующего шага, непрерывная пульсация остатка грантов, выбор подарка и общий таймер до 13 ноября 2026 года включительно по Москве. Таймер не перезапускается при обновлении страницы; после срока акция скрывается. Остаток 12 / 50 задан вручную, автоматического учёта заявок нет.

Исходник квиза — корневой `index.html`. После изменений запустите `py designs/build.py`. Новые элементы ограничены четырьмя маршрутами; общие файлы — `designs/marketing.css` и `designs/marketing.js`.
